Desafio Participa DF · LAI · LGPD

Proteção de dados para o acesso à informação

Identifique CPF, RG, telefone, e-mail, processos e outros dados pessoais em pedidos de acesso à informação, veja o risco de publicar e leve o texto anonimizado. O motor de regras é o mesmo da API em Python, agora rodando no seu navegador.

20 regras, um score, três ações

Normalização, regex com validação de dígito e de contexto, desempate por prioridade e pontuação. Com os limites de uma abordagem por regras.
